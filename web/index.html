What you are running

GitHub Pages hosts the emulator files and the generated floppy. v86 emulates the legacy PC: BIOS, CPU, RAM, VGA text memory, keyboard, and floppy controller. The guest then runs CashOS's own boot sector and 16-bit register code.

CashOS remains unaware of the web. The catalog source lives in data/catalog.csv; its SKU, UPC, department, tax class, and payment flags are compiled into the guest for now. A future admin floppy can edit the same record format.
